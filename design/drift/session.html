Session surface

  • addFile keeps the file and sends its bytes to every browser, including later arrivals (src/session/game.ts), but simplifies a mesh over 100,000 triangles, reads STL as millimetres and sends only a link, letting each browser download it are not built yet: a linked file is downloaded and its bytes sent instead, and the 512 MB cap is not enforced.
  • The snapshot doesn't say when another tab of this browser has taken the game over, so an old tab can't show itself as read-only (ADR-022); its actions are refused.
  • A player is told about a value the host never logged only once a later value of theirs is logged, the host refuses it, or they catch up after reconnecting. A host that asks for a value and never uses it, with no later exchange with that player, goes unreported. Raised with Porter.
  • A shuffled draw picks cards by their place in the deck as it is when the host logs the draw, and that order is not signed. Knowing both values first, the host can log a card put back into the deck just before, shifting which cards the draw lands on. It shows in the log, but the draw still reads as fair. A fix would sign the deck's cards as the other player sees them. Raised with Porter.
