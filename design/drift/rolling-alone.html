  • Rolling alone (ADR-023) is not on the surface yet. The record lets the host take a roll or draw alone at any time, because who is connected is not in the log. So Session must keep it fair: the host goes alone only with nobody else connected; a connected player's browser flags an alone roll or draw that arrives while it is there; a player whose signed value never reaches the log is told so. Proposed, for Porter. Session's roll line still says a missing signature is logged as tampered, but the record refuses it.
