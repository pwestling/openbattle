OpenBattle design · Level 1 · Concept

Action

Realizes: What a player can do One table
Purpose
Every change, so it can be seen, undone and replayed.
Meaning
One thing a player did that changed the table or the game: moving models, placing terrain, rolling, drawing or moving a card, changing the phase, a counter or a mark, undoing.
Invariants
  • Every change to the table is an action.
  • Everyone agrees on the order of all actions.
Not
A measurement, or anything that only changes one person's view.
