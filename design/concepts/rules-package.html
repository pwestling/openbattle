OpenBattle design · Level 1 · Concept

Rules package

Realizes: Players apply the rules
Purpose
Let a game's chores be automated, later.
Meaning
An add-on for one wargame that suggests or takes actions according to that game's rules.
Invariants
  • A package can only take actions a player could take, so a game replays without it.
  • A player can always override what a package suggests or does.
  • No package ships in the first version.
Not
Part of the engine.
Decisions: ADR-001
