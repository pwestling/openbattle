OpenBattle design · Level 1 · Concept

Rules package

Realizes: Players apply the rules
Purpose
Let a game's chores be automated.
Meaning
An add-on for one wargame that suggests or takes actions according to that game's rules. It reads the table and the log and offers the player whose step it is a suggestion: the next step, with the dice to roll. Which package a game uses is part of the game, so every browser in it runs the same one.
Invariants
  • A package can only take actions a player could take, so a game replays without it.
  • A player can always override what a package suggests or does.
  • The first version ships one package, for Grimdark Future (ADR-029).
  • A package keeps nothing of its own: it works out where the game is from the log, so a reload, a late joiner or a spectator sees the same step.
  • A package never acts on its own: every action it takes is one a player clicked.
  • A package ships no rules text and no army data; players bring their own lists (ADR-030).
Not
Part of the engine. Not a referee: it never refuses a move, and a game played by hand next to it stays valid.
