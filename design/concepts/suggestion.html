OpenBattle design · Level 1 · Concept

Suggestion

Realizes: Players apply the rules; a package helps Rules package
Status
Proposed Drafted on 2026-10-17 for the Grimdark Future package, after Porter asked to start one.
Purpose
Let a rules package help without taking the game out of the players' hands.
Meaning
One next step a package offers one player: a sentence saying what and why, such as "Scouts shoot Orc Boyz: 10 attacks, hitting on 4+", and either the actions it would take or the roll it would make. Where the rules leave a choice, such as which unit to shoot, there is one suggestion per choice.
Invariants
  • Showing a suggestion changes nothing; only taking it does.
  • Taking a suggestion is exactly the same as taking its actions by hand, each carrying the suggestion's sentence as its note.
  • A suggestion is for the player whose step it is, which is usually whoever has priority. Others see it too, so everyone knows what the game is waiting on.
  • The same log gives the same suggestions in every browser.
Not
A rules check: a suggestion never refuses a move, and ignoring it is always allowed. Not priority, which says who the game waits on; a suggestion says what they might do.
