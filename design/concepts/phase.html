OpenBattle design · Level 1 · Concept

Phase

Realizes: What a player can do Players apply the rules
Purpose
Know where the game is up to.
Meaning
The current round, whose turn it is, and the name of the current step of the turn, such as "Movement".
Invariants
  • Changing the phase is an action.
  • In the first version the players name and change phases by hand; the app attaches no rules to them.
Not
Who the game is waiting on right now, which is priority and can move inside a turn. A timer or a clock.
