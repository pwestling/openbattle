OpenBattle design · Level 1 · Concept

Game

Realizes: What it is for Games survive
Purpose
The thing the players share and come back to.
Meaning
One match, from setup to the end, reached through its link. It has players, one host, perhaps spectators, one log, and the table that log produces.
Invariants
  • A game has exactly one log.
  • A game's link never changes.
  • A game has exactly one host.
Not
A ruleset. Which wargame is being played is a name the players write down, unless the game uses a rules package, which the game then names.
