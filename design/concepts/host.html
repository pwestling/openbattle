OpenBattle design · Level 1 · Concept

Host

Realizes: One table Browser to browser Games survive
Purpose
Someone has to decide the order things happen in.
Meaning
The player who opened the game. Their browser puts every action in order.
Invariants
  • Every game has exactly one host, and it never changes.
  • While the host is away nobody can act, and everyone can see the game is paused.
  • When the host returns, the game continues from the host's copy of the log.
Not
A server, and not a referee: the host cannot overrule anything or choose dice results.
