OpenBattle design · Level 1 · Concept

Measurement

Realizes: What a player can do Feels like the real table
Purpose
Answer "how far?" exactly.
Meaning
The distance in inches between two points, or between two models measured base edge to base edge, or between a model and a marker's edge, either straight or along a path through waypoints, with any height difference shown alongside, and the distance across the table (ignoring height) shown too.
Invariants
  • The same question gets the same answer in every browser.
  • Measuring changes nothing and is not an action.
Not
A range check. Measuring never refuses or judges a distance; a rules package may use it to suggest what is in range (ADR-029).
Decisions: ADR-007
