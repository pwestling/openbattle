Grimdark Future

Realizes: Rules package Suggestion
Status
Accepted Drafted on 2026-10-17. A new module (ADR-029). Accepted by Porter on 2026-10-17.

Hides

Grimdark Future's rules: how an Army Forge list becomes stats, what each core rule and special rule does to a roll, which counters and marks it keeps on things, and how it tells from the log where the round is up to.

Knows about

Concepts
rules package, suggestion, army, unit, model, item, counter, mark, phase, priority, marker, terrain, roll, action, log, table, player, line of sight, measurement
Modules
Record, to read the log and its table and to describe actions. Measure, for ranges, charge reach, objectives and line of sight. Not Session or Screen: the package never sends anything itself.

Owns

  • The same log gives the same suggestions in every browser.
  • Every suggestion is made of actions and rolls a player could take by hand, and none is taken unless a player clicks it.
  • It keeps nothing between calls; after an undo or a step done by hand it reads the table again, and where it can't tell what happened it offers the choices again rather than guessing.
  • It holds no OnePageRules rules text or army data (ADR-030).
