Hides

How actions are written down, and how the table is worked out from the log.

Knows about

Concepts
log, action, table, model, item, unit, group, army, terrain, marker, phase, priority, counter, mark, card, deck, roll, player, game, rules package (only its name)
Modules
None.

Owns

  • The table is completely determined by the log.
  • The log only grows; undo cancels the latest action.
  • Every model is in exactly one unit, every unit in exactly one army, and no group contains itself. Every item is carried by one model or held by one item, and no item holds itself.
  • Removed models are set aside, never deleted. A model in reserve is set aside too, and kept apart from removed models.
