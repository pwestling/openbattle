OpenBattle design · Level 2 · Boundary

Session

Realizes: Host Game Player Spectator Roll Deck Action Live view

Hides

Which browser is the host, how actions get one agreed order, how a returning or lagging browser catches up, how dice results and card draws are made and checked, and how mesh files reach every browser.

Knows about

Concepts
game, player, spectator, host, action, roll, log, table, deck, card, live view
Modules
Record, Link, Archive.

Owns

  • Everyone agrees on the order of all actions.
  • Every player's live view reaches everyone in the game, and never enters the log.
  • Every roll is made once and every browser checks it; a roll that fails the check is shown to everyone.
  • Nobody can act while the host is away, and everyone sees the pause.
  • A player stays the same player after a reload.
  • Spectators receive the game and never send actions.
  • Every browser in the game gets every mesh file the table uses.
