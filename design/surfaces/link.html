Carries messages between the browsers in one game. It never looks inside them.

connect(link: string): Promise<Link>

Pre
None.
Post
This browser is announced at the relay under the game's link and connects directly, or through TURN, to every other browser announced there. It has a browserId that stays the same for this browser: base64url of the first 16 bytes of SHA-256 of its public key, from a key pair the browser makes on first use and can never read the private half of. Before a connection counts, each browser signs a fresh challenge from the other; a browser that cannot sign for the id it claims is refused, and any connection already made to the real one stays. Opening the game in another tab of the same browser moves this browser there: the earlier tab's link loses every connection, as if closed.
Fails
Rejects if the relay cannot be reached, or if it refuses this browser's proof of id (only a tampered browser).

link.send(message: Json, to?: browserId): void

Pre
None.
Post
The message is delivered whole, after earlier messages to the same browser, to one browser or to all of them.
Fails
Messages to a browser that is not connected are dropped; the caller learns of it through onChange.

link.onMessage(listener: (message: Json, from: browserId) => void): () => void

Pre
None.
Post
The listener receives every message for this browser. from is an id the sender has proven, never one it claims in the message.
Fails
Never.

link.onChange(listener: (connected: browserId[]) => void): () => void

Pre
None.
Post
The listener is called with the browsers currently connected whenever one arrives or leaves.
Fails
Never.

link.close(): void

Pre
None.
Post
All connections close and the relay forgets this browser.
Fails
Never.

link.publicKey: string and link.sign(data: string): Promise<string>

Pre
None.
Post
This browser's raw P-256 public key, and its signature of the text (as UTF-8), both base64url. What is signed this way can never pass as the link's own proof of id.
Fails
Never.

verify(publicKey: string, data: string, signature: string): Promise<boolean>

Pre
None. It needs no link, so a spectator or a saved file can be checked too.
Post
True only if the signature was made by link.sign of that text in the browser with that public key.
Fails
Never: a malformed key or signature is false.

thisBrowser(): Promise<{ id: browserId; publicKey: string }>

Pre
None.
Post
This browser's id and public key, without connecting, so a new game's link can name its host. Makes the key pair if this is the browser's first use.
Fails
Never.

idFor(publicKey: string): Promise<browserId>

Pre
None.
Post
The browserId that belongs to the public key, so a key in the log can be matched to a player.
Fails
Rejects if it is not a public key.
