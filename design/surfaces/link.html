Proposed
The marked addition, from the Link and Relay build, 2026-10-15. Awaiting Porter.

Carries messages between the browsers in one game. It never looks inside them.

connect(link: string): Link

Pre
None.
Post
This browser is announced at the relay under the game's link and connects directly, or through TURN, to every other browser announced there. It has a browserId that stays the same for this browser. Opening the game in another tab of the same browser moves this browser there: the earlier tab's link loses every connection, as if closed.
Fails
Rejects if the relay cannot be reached.

link.send(message: Json, to?: browserId): void

Pre
None.
Post
The message is delivered whole, after earlier messages to the same browser, to one browser or to all of them.
Fails
Messages to a browser that is not connected are dropped; the caller learns of it through onChange.

link.onMessage(listener: (message: Json, from: browserId) => void): () => void

Pre
None.
Post
The listener receives every message for this browser. from comes from the connection itself, never from the message.
Fails
Never.

link.onChange(listener: (connected: browserId[]) => void): () => void

Pre
None.
Post
The listener is called with the browsers currently connected whenever one arrives or leaves.
Fails
Never.

link.close(): void

Pre
None.
Post
All connections close and the relay forgets this browser.
Fails
Never.
