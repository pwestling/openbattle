Keeps games in this browser, and turns them into files and back.

save(link: string, saved: { log: Log, me: PlayerId | "watch" }): Promise<void>

Pre
None.
Post
The game and who this browser is in it are stored, replacing what was stored for that link. Stored games outlive the tab.
Fails
Rejects if the browser refuses storage, for example in a private window; the session shows that the game is not being kept.

load(link: string): Promise<{ log, me } | null>

Pre
None.
Post
What was last saved for that link, or null.
Fails
Never; unreadable data counts as nothing saved.

toFile(link: string, log: Log): Blob

Pre
None.
Post
A file holding the whole log, with a format version, named after the game and the date.
Fails
Never.

fromFile(file: Blob): Promise<{ link, log }>

Pre
None.
Post
The game in the file, ready to open as a new game or to look back through.
Fails
Rejects if the file is not a saved game, or was made by a newer version.
