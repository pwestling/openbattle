Archive surface

Realizes: Archive
Status
Accepted First draft, 2026-10-14. Accepted by Porter on 2026-10-15. Revised from the Archive build, accepted by Porter on 2026-10-15: toFile returns a promise, saved files carry card pictures, files never kept are left out, and opening a file keeps its files.

Keeps games in this browser, and turns them into files and back.

save(link: string, saved: { log: Log, me: PlayerId | "watch" }): Promise<void>

Pre
None.
Post
The game and who this browser is in it are stored, replacing what was stored for that link. Stored games outlive the tab.
Fails
Rejects if the browser refuses storage, for example in a private window; the session shows that the game is not being kept.

load(link: string): Promise<{ log, me } | null>

Pre
None.
Post
What was last saved for that link, or null.
Fails
Never; unreadable data counts as nothing saved.

keepFile(link: string, file: Blob): Promise<Fingerprint> and getFile(fingerprint): Promise<Blob | null>

Pre
None.
Post
A kept file is stored under the fingerprint of its bytes and outlives the tab; the same bytes are only stored once.
Fails
As save.

toFile(link: string, log: Log): Promise<Blob>

Pre
None.
Post
A file holding the whole log and every mesh and card picture the game uses that this browser has kept, with a format version, named after the game and the date, such as OpenBattle k3j9x 2026-10-15.openbattle. A file this browser never kept is left out; opening the saved game then shows that piece or picture as missing.
Fails
Never; it is a promise only because kept files are read from storage.

fromFile(file: Blob): Promise<{ link, log }>

Pre
None.
Post
The game in the file, ready to open as a new game or to look back through. The meshes and pictures in the file are kept in this browser, as keepFile would.
Fails
Rejects if the file is not a saved game, or was made by a newer version.
