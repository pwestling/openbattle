OpenBattle design · Level 3 · Surface

Screen surface

Realizes: Screen
Status
Proposed First draft, 2026-10-14.

The screen's outside is the person using it. Each section is a place or a gesture. Mouse and keyboard controls follow Tabletop Simulator's where it has one.

Start page

Shows
New game (your name, colour, table size, 60 × 44 by default) and Open a saved file.
Does
New game opens the table as host, with the invite link ready to copy. A file opens as a new game starting from that log.
Fails
If the server can't be reached, says so and offers to retry.

Arriving from a link

Shows
Your name and colour with Join, or Watch. Someone returning on the same browser skips this and goes straight back to their seat.
Fails
A broken link goes to the start page with a message.

The table

Camera
Right-drag turns around the table, middle-drag or the arrow keys slide, the wheel zooms. One key snaps to straight down, another back to your table edge. The camera is yours alone.
Picking up
Click a model to select it; click again or double-click to select its whole unit; drag a box to select several. Dragging lifts the selection off the table and carries it, keeping its shape; Q and E turn it. Letting go sets it down: one move action.
While carrying
A line from where each model started shows the inches moved, live. Pressing the waypoint key (or a right-click) pins a corner, so a path around terrain is measured along its true length. The path stays visible to everyone after the move.
Ruler
Hold the ruler key and drag between two spots, or from a selected model, pinning waypoints the same way. Shows inches across along the whole path, and the height difference. Private; nothing is sent.
Models
The base at its true size with the model's mesh on it, or a simple stand-in body in the player's colour where there is no mesh, and a small label. When adding to an army, a mesh file can be chosen for each unit or model.
Fails
If a move is refused (host away, or a problem), the models settle back where they were and a short note says why.

Dice tray

Shows
How many dice, how many sides (six by default), an optional label, and Roll. Recent rolls stay in the tray.
Does
Dice are thrown onto the tray and land on the decided result, for everyone at once, then line up sorted. A tampered roll is shown in red with a warning.

Panels

Phase bar
Round, whose turn, phase name; each can be changed by a player.
Army
Each player's units and groups with their counters and marks. Change a counter with + and −, toggle a mark, set models aside or return them. Paste or type a list to add units or models to your army, at the start or at any point in the game.
Terrain
Add a box, cylinder or ramp, or load a 3D mesh file (.glb, .gltf, .obj or .stl), then size, move and turn it like a model. A model set down over terrain lands on the highest floor under it; while carrying, Page Up and Page Down (or Shift with the wheel) step between the floors there. Models pass through walls; nothing pushes them away.
Log
Every action as a sentence ("Ana moved Scouts 5.8″"). A slider looks back through the game; the table shows that moment, read-only, until you return to now. Undo appears beside your own latest action.
Save
Saves the game to a file. Available to players and spectators.

Connection banner

Shows
Nothing while all is well. "Connecting…", or "Waiting for the host. The game is paused" with the table read-only, or "Your table differs from the host's" with a button to reload the host's copy.
