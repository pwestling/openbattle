What the server offers browsers, over HTTPS at the site's address. This is a published protocol: changes only add, within a version.

WebSocket /signal?game={link}

Pre
The game link is made of letters, digits, - and _.
Post
The server tells this browser who else is announced under that link, tells the others when browsers arrive and leave, and forwards { to, data } handshake messages between them. It keeps nothing once everyone has gone. If the same browser announces itself again under the link, from another tab or visit, the newest one stays: the earlier socket is closed and the others see that browser leave and arrive again.
Fails
Closes the socket if a message is over 64 KB. Handshake messages are a few KB, so this only stops someone using the relay to push bulk data through our server. Also closes the socket if the first message is not the browser announcing itself, or a message is not in the protocol.
