What the server offers browsers, over HTTPS at the site's address. This is a published protocol: changes only add, within a version.

WebSocket /signal?game={link}

Pre
The game link is 8 to 64 safe characters.
Post
The server tells this browser who else is announced under that link, tells the others when browsers arrive and leave, and forwards { to, data } handshake messages between them. It keeps nothing once everyone has gone.
Fails
Closes the socket if more than 16 browsers are announced under one link, or if a message is over 64 KB.

GET /turn

Pre
None.
Post
A TURN address, user name and password, valid for 24 hours.
Fails
503 if TURN is not configured; browsers then try only direct connections.

GET /health

Pre
None.
Post
Whether signalling and TURN are up, as JSON.
Fails
Never.
