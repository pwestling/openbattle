OpenBattle design · Level 3 · Surface

Measure surface

Realizes: Measure
Status
Proposed First draft, 2026-10-14.

Two operations, both pure functions.

distance(table: Table, from: Spot, to: Spot, via?: Point[]): { across, up }

A Spot is a point in inches, a model, or a unit. via is an optional list of waypoints, for a path around terrain.

Pre
Named models and units are on the table.
Post
across is the distance in inches across the table: with no waypoints, the shortest one, base edge to base edge, and for a unit its closest model; with waypoints, the length of the path from the first spot through each waypoint in order to the last, measured from base edges at the two ends. up is the height difference between their bases, which for a model on a terrain floor is that floor's height. Both are rounded to a hundredth of an inch, and the same in every browser.
Fails
Throws if a named model is set aside or does not exist.

floors(mesh: Mesh, size: { width, depth, height }): Floor[]

A Floor is a flat outline at one height, in the piece's own inches.

Pre
The mesh has been read from its file.
Post
The mesh's upward-facing flat areas, with nearby ones at almost the same height merged, and any too small to hold a 25 mm base left out. At most 12 per piece, the largest kept. The same mesh and size always give the same floors.
Fails
Never; a mesh with no flat areas has no floors, and models then stand on the table beneath it.
