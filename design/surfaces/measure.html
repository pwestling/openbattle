Measure surface

Realizes: Measure
Status
Proposed First draft, 2026-10-14.

One operation. A pure function of the table.

distance(table: Table, from: Spot, to: Spot): { across, up }

A Spot is a point in inches, a model, or a unit.

Pre
Named models and units are on the table.
Post
across is the shortest distance in inches across the table between the two, base edge to base edge; for a unit, its closest model. up is the height difference between their bases. Both are rounded to a hundredth of an inch, and the same in every browser.
Fails
Throws if a named model is set aside or does not exist.
Decisions: ADR-010
