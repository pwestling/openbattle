Three operations, all pure functions.

distance(table: Table, from: Spot, to: Spot, via?: Point[]): { across, up }

A Spot is a point in inches, a model, a unit, or a marker, measured to its edge (ADR-025). via is an optional list of waypoints, for a path around terrain.

Pre
Named models, units and markers are on the table.
Post
across is the distance in inches across the table: with no waypoints, the shortest one, base edge to base edge, and for a unit its closest model; with waypoints, the length of the path from the first spot through each waypoint in order to the last, measured from base edges at the two ends. up is the height difference between their bases, positive when the far end stands higher, which for a model on a terrain floor is that floor's height. Both are rounded to a hundredth of an inch, and the same in every browser.
Fails
Throws if a named model is set aside or does not exist, or a named unit has no model on the table.

floors(mesh: Mesh, size: { width, depth, height }): Floor[]

A Floor is a flat outline at one height, in the piece's own inches.

Pre
The mesh has been read from its file, with up and handedness as three.js reads it; it is stretched to the given size.
Post
The mesh's upward-facing flat areas, with nearby ones at almost the same height merged into one. The same mesh and size always give the same floors.
Fails
Never; a mesh with no flat areas has no floors, and models then stand on the table beneath it.

sight(table: Table, bodies: Bodies, from: Model, to: Model | Point, ignore?: Piece[]): { seen, hiddenBy, line }

Line of sight from one model to another model, or to a point in inches with a height. Bodies holds the mesh of every model and terrain piece that has one, read from its file; the others use their simple solid or stand-in body. ignore lists pieces that don't count as in the way; the looker and the target never do.

Pre
Both models are on the table. Every mesh on the table is in bodies.
Post
seen is how much of the target's body some part of the looker's body can see, from 0 (not seen) to 1, judged from points spread evenly over both bodies and rounded to a hundredth; a point is either seen (1) or not (0). hiddenBy lists the pieces that hide the parts of the target the looker can't see: each piece that alone stands in the way of some line to such a part, or, where pieces overlap so that none is alone, those in the way of the least hidden line. A point on a surface, such as a spot on a roof, is not hidden by that surface. line is one clear sight line, two points, when anything is seen, for the screen to draw. Bases are not part of any body. A model on a floor is raised to that floor. Whether anything is seen is the same with the looker and a model target swapped. The same in every browser.
Fails
Throws if a named model is not on the table or does not exist, or a mesh on the table is missing from bodies.
