Status

Minor fixes from the scaffold review, 2026-10-15: act leaves roll, draw and join to their own operations; the snapshot says whether the game is kept; the other player signs their value (ADR-022). open takes an optional starting log, so a saved file opens as a new game; decided on 2026-10-15 under Porter's instruction to go with the best guess on easily reversed calls while he was away. From the Session build, 2026-10-15, while Porter slept: the game's link names its host, the snapshot's link is the address to share, enter takes that address or the link, a missing signature is refused rather than flagged (unless the roll is taken alone), the host refuses a badly signed value, a whole log from the host is taken only when asked for and only if it extends this browser's, and the browser that started a game but no longer has it can't take it back.

Two ways in, and seven operations on the session you get back. Everything a screen shows comes from one snapshot.

open(size: { width, depth }, me: { name, colour }, from?: Log): Promise<Session>

Pre
None.
Post
A new game with a fresh link. This browser is its host and has joined as a player. The game is saved. Given a starting log (from a saved file), the new game starts from that log instead (Record's reopen), with this browser as its host; it joins as me unless its key is already one of the log's players. Other players come in by the new link.
Fails
Rejects if the relay cannot be reached, or a starting log has no players; nothing is saved.

A game's link is 8 random characters, a dash and the host's browser id, so every browser knows who the host is before trusting anything it is sent (ADR-022); a game opened from a saved file adds a dash and the number of entries copied. The address to share is the page's address with ?game= and the link, and enter takes either.

enter(link: string, as: { name, colour } | "watch"): Promise<Session>

Pre
None.
Post
If this browser has been in the game before, it comes back as who it was (the host comes back as host, and the game resumes from its saved log). Otherwise it joins as a new player, or as a spectator with "watch", once it has caught up with the host.
Fails
Rejects if the link is malformed, or if this browser started the game but no longer has it. If the host is away, it still resolves, with the snapshot saying so.

session.act(action: Action): Promise<void>

Pre
This browser is a player. The action is any kind but roll, draw and join, which have their own operations (roll, draw, and open or enter).
Post
Resolves once the host has put the action in the log and this browser has it.
Fails
Rejects, with nothing logged, if the host is away, this browser is a spectator, or the record finds a problem with the action.

session.roll(dice: number, sides: number, label?: string): Promise<number[]>

Pre
This browser is a player; 1 to 1024 dice, of at least two sides. The cap stops a typo from freezing every browser in the game.
Post
Resolves with the numbers that came up, after the sealed exchange of ADR-008 and with the roll in the log. The other player (the roller, or when the host rolls, a player who is not the host) signs their value together with the game's link, the dice and the host's seal, and for their own roll only after checking the host describes the roll they asked for, and every browser checks the signature as the roll arrives and when a saved game is loaded (ADR-022). When no other player is connected, the host rolls alone (ADR-023, proposed): its browser makes both values, nobody signs, and the roll is marked as rolled alone for everyone. With another player connected, the host always uses the sealed exchange.
Fails
Rejects as act does, or if the other player does not send their value. A roll whose check fails is still logged, flagged as tampered, as is one whose signature does not check in a browser that receives it; the host itself refuses a value whose signature does not check, with nothing logged. The record refuses a roll with no signature unless it is marked as rolled alone.

session.draw(deck: DeckId, cards: number, to: "hand" | "table"): Promise<CardId[]>

Pre
This browser is a player, and the deck holds at least that many cards.
Post
Resolves with the cards drawn, with the draw in the log. An ordered deck gives its top cards straight away; a shuffled deck picks them with the same sealed exchange as a roll. The host draws from a shuffled deck alone, as it rolls alone, when no other player is connected. Cards drawn to the hand go to this player's hand; cards drawn to the table land face up.
Fails
As act, and for a shuffled deck as roll; also rejects if the deck has too few cards.

session.watch(listener: (now: Snapshot) => void): () => void

A Snapshot holds: the game's link; who this browser is; the log and the current table; the connection (connecting, playing, host away); whether browsers disagree; which rolls and draws failed their signature check; which rolls and draws the host took alone while this browser was connected as a player, which the host should not do (ADR-023); the rolls and draws this browser signed a value for that the host never logged; and whether the game is being kept in this browser, which it is not when the browser refuses storage.

Pre
None.
Post
The listener is called now and after every change. The returned function stops it.
Fails
Never.

session.resync(): Promise<void>

Pre
The snapshot says this browser disagrees with the host.
Post
This browser's log is replaced by brought up to the host's, and the snapshot agrees again.
Fails
Rejects if the host is away, or if the host's log changes entries this browser already has, which stays shown as a disagreement; nothing changes.

session.addFile(source: Blob | URL): Promise<Fingerprint>

Pre
This browser is a player. The source is a .glb, .gltf, .obj or .stl mesh, or a .png, .jpg or .webp picture for a card: either the file itself, or an https link anyone can download it from (such as S3). Either way the mesh is at most 512 MB, so loading it cannot run a browser tab out of memory.
Post
A mesh with more than 100,000 triangles is first simplified in this browser to about that many, keeping its outline and height; STL files, which are usually in millimetres, are read as millimetres. A file is kept with the game and its bytes are sent to every browser in it, including any that join later. A link is downloaded here first, to take its fingerprint, then only the link is sent and each browser downloads it itself, checking the fingerprint. If the linked mesh had to be simplified, the simplified bytes are sent instead of the link, since the link would serve the original. Resolves with the fingerprint, which a place terrain or add to army action can then name.
Fails
Rejects if the source is not a readable mesh, is over 512 MB, or the link cannot be downloaded; nothing is sent. If another browser later downloads a link and gets different bytes, it shows that piece as missing and asks the player who added it to send the file itself.

session.leave(): void

Pre
None.
Post
The connection closes. The saved game stays, so enter with the same link comes back.
Fails
Never.
