OpenBattle design · Level 3 · Surface

Session surface

Realizes: Session
Status
Proposed First draft, 2026-10-14.

Two ways in, and five operations on the session you get back. Everything a screen shows comes from one snapshot.

open(size: { width, depth }, me: { name, colour }): Session

Pre
None.
Post
A new game with a fresh link. This browser is its host and has joined as a player. The game is saved.
Fails
Rejects if the relay cannot be reached; nothing is saved.

enter(link: string, as: { name, colour } | "watch"): Session

Pre
None.
Post
If this browser has been in the game before, it comes back as who it was (the host comes back as host, and the game resumes from its saved log). Otherwise it joins as a new player, or as a spectator with "watch", once it has caught up with the host.
Fails
Rejects if the link is malformed. If the host is away, it still resolves, with the snapshot saying so.

session.act(action: Action): Promise<void>

Pre
This browser is a player. The action is any kind but roll.
Post
Resolves once the host has put the action in the log and this browser has it.
Fails
Rejects, with nothing logged, if the host is away, this browser is a spectator, or the record finds a problem with the action.

session.roll(dice: number, sides: number, label?: string): Promise<number[]>

Pre
This browser is a player; 1 to 100 dice of 2 to 100 sides.
Post
Resolves with the numbers that came up, after the sealed exchange of ADR-008 and with the roll in the log.
Fails
Rejects as act does, or if the other player does not send their value. A roll whose check fails is still logged, flagged as tampered.

session.watch(listener: (now: Snapshot) => void): () => void

A Snapshot holds: the game's link; who this browser is; the log and the current table; the connection (connecting, playing, host away); and whether browsers disagree.

Pre
None.
Post
The listener is called now and after every change. The returned function stops it.
Fails
Never.

session.resync(): Promise<void>

Pre
The snapshot says this browser disagrees with the host.
Post
This browser's log is replaced by the host's, and the snapshot agrees again.
Fails
Rejects if the host is away; nothing changes.

session.leave(): void

Pre
None.
Post
The connection closes. The saved game stays, so enter with the same link comes back.
Fails
Never.
