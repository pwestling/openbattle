ADR-033: A roll names what it is about, and one mark or counter covers several things

Status
Accepted From the review of the Grimdark Future package design, 2026-10-17. Porter chose "Both" and accepted it on 2026-10-17.
Context
The package's defender steps (roll blocks, remove models) must know which unit was shot, but a roll carries only its label, so the package would read unit names back out of words. Players often have two units with the same name, and rewording a label later would change what old games suggest. Ending a round clears marks on every unit, which takes one action per unit: a long log and an undo per unit.
Decision
A roll may name what it is about, as typed targets (ADR-032), such as the shooting unit and its target. That list is signed with the roll, as its label is, and kept on the table's roll; the label stays words only. A counter or mark action names one or more targets, and sets the same counter or mark on each, as a move moves several models.
Because
The package matches on ids, never on words, so repeated names and reworded labels change nothing. One step a player took is one line in the log and one undo.
Rejected
Making target picks into actions: Porter chose that picks are not actions (ADR-031). Grouping several actions into one: a new idea in the record for one use.
Affects
Roll, Counter, Mark, Record, Session, Grimdark Future
