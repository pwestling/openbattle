OpenBattle design · Level 1 · Decision

ADR-004: One host for the whole game, with no hand-over

Status
Accepted Accepted with Porter's additions: resume from the host after it drops, and spectators who can save.
Context
Someone must put actions in order. The first attempt elected a new host automatically when the host left, which was a large and subtle part of its networking.
Decision
The player who opens the game is its host for good. When the host drops, the game pauses for everyone and says so; when the host returns from the same link, the game continues from the host's stored log. Spectators can join, and any player or spectator can save the game to a file.
Because
Waiting for the host is acceptable among friends, and it removes the hardest part of the networking. Every browser keeps the whole log, so nobody loses the game.
Rejected
Automatic hand-over: complex and bug-prone. No host at all: browsers could disagree about order.
Affects
host, spectator, Session
