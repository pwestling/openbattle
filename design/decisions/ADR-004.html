OpenBattle design · Level 1 · Decision

ADR-004: One host for the whole game, with no hand-over

Status
Proposed
Context
Someone must put actions in order. The first attempt elected a new host automatically when the host left, which was a large and subtle part of its networking.
Decision
The player who opens the game is its host for good. When the host is away the game pauses for everyone and says so, and it resumes when the host comes back from the same link.
Because
For two friends, waiting for the host is acceptable, and it removes the hardest part of the networking. Every browser keeps the whole log, so a manual "take over" can be added later.
Rejected
Automatic hand-over: complex and bug-prone. No host at all: two browsers could disagree about order.
