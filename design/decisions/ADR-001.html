OpenBattle design · Level 0 · Decision

ADR-001: The first version is a shared table, not a rules engine

Status
Proposed
Context
OpenBattle could automate a game's rules or leave the rules to the players. The first attempt built a general engine that loaded rules as sandboxed add-ons, plus three game systems, before any one game was pleasant to play.
Decision
The app handles the physical parts of the table (positions, measuring, dice, counters, the log) and enforces no rules.
Because
A table two friends can finish a game on is useful by itself and small enough to build well. Rules automation multiplies the work for every game.
Rejected
Automating one game's rules from the start: bigger scope, and rules code shapes the core before we know what players want automated. A general rules add-on system: what the first attempt collapsed under.
Affects
The players apply the rules, terrain, army, measurement, roll
