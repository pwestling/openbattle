OpenBattle design · Level 2 · Decision

ADR-011: The link knows nothing about games

Status
Proposed
Context
The connection layer could understand game messages, or just carry them.
Decision
The link carries opaque messages between the browsers of one game and reports when the connection is up or down.
Because
Connection code changes for network reasons and game code for game reasons; keeping them apart stops each one's churn reaching the other.
Rejected
A link that understands actions: couples the two fastest-changing parts.
Affects
Link
