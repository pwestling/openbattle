ADR-016: The screen reads one snapshot from the session

Status
Accepted Accepted by Porter on 2026-10-15.
Context
The screen needs to know about new actions, connection changes, disagreements and who it is.
Decision
The session offers a single watch that hands over a complete snapshot after every change, instead of a separate notification for each kind of event.
Because
The screen can't miss or misorder an event, and it redraws from one consistent picture. A game's state is small, so handing over the whole snapshot costs little.
Rejected
One callback per event kind: more surface, and every new kind is another thing the screen must remember to handle.
Affects
Session surface
