OpenBattle design · Level 2 · Decision

ADR-013: Deploy to Craftworld by pull

Status
Proposed
Context
The app, signalling and TURN run on Craftworld (vps-01, NixOS). The first attempt's deploy worked: the server pulled each release built from main.
Decision
Keep that shape: a NixOS module runs the web server, signalling and TURN; a timer pulls each release, checks it, switches to it, health-checks it, and rolls back on failure. The site is openbattle.thehivemind5.com.
Because
Nothing in GitHub can reach the server, and Porter already runs it this way.
Rejected
Pushing from GitHub to the server: needs a deploy key on the server's front door.
Affects
Relay
