OpenBattle design · Level 2 · Decision

ADR-012: The screen draws with React and SVG

Status
Proposed
Context
The screen needs a way to draw the table and the panels around it.
Decision
Panels in React; the table as SVG, in inches, scaled to the window.
Because
SVG keeps measurements exact at any zoom and is easy to hit-test. React is well known and only the screen knows about it.
Rejected
Canvas or WebGL: faster for thousands of models, which a game doesn't have, and harder to make precise and accessible.
Affects
Screen
