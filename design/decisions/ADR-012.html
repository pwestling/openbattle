OpenBattle design · Level 2 · Decision

ADR-012: The screen uses three.js for the table and React for panels

Status
Proposed Revisited after the table became 3D.
Context
The screen draws a 3D table and information panels around it.
Decision
The table is drawn with three.js (WebGL), in inches. Panels such as the log, the army list and counters are React.
Because
three.js is the most widely used 3D library for the web, small enough to stay in one module, and the first attempt's table used it. React is well known and only the screen knows about it.
Rejected
Babylon.js: capable, but heavier and with its own scene and UI system we don't need. A game engine exported to the web: large downloads and a second toolchain. SVG: flat only.
Affects
Screen
