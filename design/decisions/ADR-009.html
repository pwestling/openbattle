OpenBattle design · Level 1 · Decision

ADR-009: Undo takes back only the latest action

Status
Accepted
Context
Players need to take back mistakes. The first attempt let any action anywhere in history be undone, with a web of dependent actions undone with it.
Decision
Undo cancels the latest action in the game that hasn't been cancelled, and only the player who took it can undo it.
Because
Easy to understand and impossible to tangle. Mistakes are almost always noticed straight away.
Rejected
Undoing any past action: hard to explain what else disappears with it.
