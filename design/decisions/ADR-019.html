OpenBattle design · Level 1 · Decision

ADR-019: Terrain can be a mesh loaded from a file

Status
Proposed From Porter's surface review on 2026-10-15.
Context
Real scenery has shapes no box or cylinder captures, and players already have scenery meshes, for example from Tabletop Simulator. The surfaces only allowed simple solids.
Decision
A terrain piece is either a simple solid or a mesh from a .glb, .gltf or .obj file of up to 25 MB. The log names a mesh by the fingerprint of its file's bytes. The file travels browser to browser through the session, is kept with the game in each browser, and is included in a saved game file. Models set down on a mesh rest on its surface.
Because
The fingerprint guarantees everyone draws the same scenery and keeps the log small. Sending files between browsers keeps the server out of the game, as ADR-006 requires.
Rejected
Links to meshes on the web: they break, change, or differ between browsers. Uploading meshes to the server: the server would store game content. Simple solids only: scenery wouldn't look or feel like the real thing.
Affects
Terrain, Session, Archive, Session surface, Archive surface
