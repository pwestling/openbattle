OpenBattle design · Level 0 · Decision

ADR-006: Games are kept only in the browsers

Status
Accepted
Context
Games must survive reloads and dropped connections, and the server should stay simple.
Decision
Each browser keeps its copy of the log in browser storage that outlives the tab. A game can be saved to a file and loaded back. The server keeps nothing.
Because
The server stays stateless and cheap, and there is nothing private on it to protect.
Rejected
Server storage: needs accounts, backups and a privacy story. Per-tab storage, as in the first attempt: lost when the tab closes.
Affects
Games survive, Archive
