OpenBattle design · Level 2 · Decision

ADR-005: Our own signalling and TURN on Craftworld

Status
Proposed
Context
Browsers need help to find each other, and sometimes a relay to reach each other. The first attempt used a library that met through public relays and needed workarounds for dropped connections.
Decision
Run a small signalling server and a TURN server on Craftworld, and connect browsers with WebRTC.
Because
No outside service sits between the players, and connection problems show up in our own server logs.
Rejected
Public meeting relays through a library: an outside dependency we can't see into. Sending all game traffic through the server: not browser to browser.
Affects
Link, Relay
