ADR-014: OnePageRules is the yardstick, and its names may ship

Status
Accepted Porter's call on 2026-10-14. OnePageRules' written terms for software were not found on their site; Porter's understanding is that this use is allowed.
Context
The intent needed one real game to measure the first version against, and the first attempt banned all publisher names from the repository.
Decision
The first version is done when two players finish a full OnePageRules game on it, starting with Grimdark Future. OnePageRules names may appear in the app and the repository. Content from Games Workshop and other publishers still never ships. OnePageRules' rules text and army stats don't ship either; the package ships only mechanics and names (ADR-030).
Because
OnePageRules games are free, widely played, and built on the units, phases and counters the engine already knows. Being able to use their names makes examples and tests realistic.
Rejected
Keeping every publisher's names out: needlessly awkward for a game whose publisher is relaxed about it. Measuring against a Games Workshop game: its content can't ship.
Affects
How we would know it worked, Whose content we ship, army
