ADR-021: Decks with draws nobody can rig, and hands hidden on screen

Status
Proposed From Porter's review on 2026-10-15.
Context
Many games draw cards (missions, objectives, events). Porter asked whether draws can be as tamper-evident as dice, accepting that someone inspecting their browser's data could see hidden cards.
Decision
A deck is a face-down pile with no order decided in advance. Each draw picks its cards at random from what's left, using the same sealed exchange as a roll (ADR-008), and every browser checks it. Cards go into the drawer's hand or face up on the table. Other players' hand cards are shown face down, but they are in every browser's log.
Because
Drawing at the moment of the draw means there is no stored order anyone could peek at or arrange, and the sealed exchange stops the host or the drawer steering the pick. Hiding hands on screen only is enough among friends, and costs nothing extra.
Rejected
Shuffling the whole deck up front: the order would sit in every browser's log, so the next card could be read ahead. Truly secret hands: needs a heavier cryptographic card protocol in which no browser ever holds other players' cards; possible later if wanted.
Affects
Card, Deck, Record surface, Session surface, Screen surface, ADR-015
