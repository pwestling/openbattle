OpenBattle design · Level 1 · Decision

ADR-008: Dice are tamper-evident

Status
Proposed Replaces "the host rolls the dice", per Porter's review on 2026-10-14.
Context
Dice cheating happens on Tabletop Simulator. In a host-ordered game, a host that simply rolls could pick its results.
Decision
Every roll's result is computed from two random values: one the host committed to (sent in sealed form) before the roll was asked for, and a fresh one from the other player, sent after seeing the seal. The host then opens the seal, and every browser recomputes the result and checks it. A roll that fails the check is shown to everyone as tampered.
Because
Neither the host nor the other player can steer a result: each picks their value without knowing the other's. It costs one extra message per roll.
Rejected
The host alone rolls (the first proposal): trusts the host. A server rolls: the server would take part in games. Limits: the host could still stall instead of opening a seal, but that is visible to everyone; and this protects dice, not other actions.
Affects
Dice nobody can fix, roll, host, Session
