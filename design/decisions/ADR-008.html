OpenBattle design · Level 1 · Decision

ADR-008: The host rolls the dice

Status
Proposed
Context
Dice results must be the same for both players and decided once.
Decision
The host's browser throws every roll and the result goes into the log.
Because
Simple, and everyone sees every result. This trusts the host, which suits friends.
Rejected
A shared random scheme where neither side can cheat: extra protocol for a problem friends don't have yet.
Affects
roll, host, Session
